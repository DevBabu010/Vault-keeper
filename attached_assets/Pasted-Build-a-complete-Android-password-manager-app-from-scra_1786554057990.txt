Build a complete **Android password manager app** from scratch called **Vault Keeper**.

This is a **local-only personal password vault**. It should work offline and should not require a backend, server, cloud database, account, or internet connection.

Use the **mobile app development environment supported by Replit** and make the project capable of being built into an Android APK.

## 1. DESIGN STYLE

The entire app should use a **Dark Neon Glassmorphism** design.

Use the attached reference image as inspiration for the visual language.

Design characteristics:

* Very dark navy/black background
* Frosted/translucent glass cards
* Rounded corners
* Subtle glass borders
* Soft shadows
* Neon green accent
* Green ambient glow
* Glowing gradient buttons
* White headings
* Muted blue-gray secondary text
* Premium minimalist appearance
* Spacious layout
* Smooth subtle animations

Do NOT make the entire UI green.

Use neon green mainly for:

* Primary buttons
* Active navigation items
* Focused input borders
* Important icons
* Security indicators
* Subtle glow effects

The final design should feel like a **premium futuristic security application**.

# 13. SECURE STORAGE

This is extremely important.

The application is a password manager, so do NOT use insecure plaintext storage.

Use the Android platform's secure cryptographic facilities.

Requirements:

* Use Android Keystore where appropriate.
* Use authenticated encryption such as AES-GCM for sensitive vault data.
* Generate cryptographically secure random IVs/nonces.
* Never hard-code encryption keys.
* Never store the master password in plaintext.
* Never store passwords in plaintext files.
* Never put passwords in logs.
* Never send passwords to an external server.
* Do not use Base64 as a replacement for encryption.
* Do not implement homemade cryptography.

If the chosen mobile framework has a secure-storage API, use the platform-supported secure storage mechanism appropriately.

Keep encryption/key-management code separate from UI code.
